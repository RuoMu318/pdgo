# Flowstate Task Decomposition metadata

## Scenario

Split work into independently verifiable tasks

## Boundaries

- Do not use outside planning and discovery scenarios
- Do not bypass approval, scope, evidence, or safety gates

## Inputs

- classified project context
- plan or task-local artifacts
- current constraints

## Outputs

- task ledger
- evidence, risks, blockers, and next action

## Prerequisites

- FlowState startup classification
- declared scope
