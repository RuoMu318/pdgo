# Flowstate User Clarification metadata

## Scenario

Resolve an unanswered decision before planning or execution

## Boundaries

- Do not use outside coordination and governance scenarios
- Do not bypass approval, scope, evidence, or safety gates

## Inputs

- classified project context
- plan or task-local artifacts
- current constraints

## Outputs

- clarification record
- evidence, risks, blockers, and next action

## Prerequisites

- FlowState startup classification
- declared scope
