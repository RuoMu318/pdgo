# Flowstate Skill Routing Review metadata

## Scenario

Check routing candidates against a scenario

## Boundaries

- Do not use outside skill authoring and routing scenarios
- Do not bypass approval, scope, evidence, or safety gates

## Inputs

- classified project context
- plan or task-local artifacts
- current constraints

## Outputs

- routing decision
- evidence, risks, blockers, and next action

## Prerequisites

- FlowState startup classification
- declared scope
