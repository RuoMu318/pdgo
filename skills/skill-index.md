# Active PDGO Skill Index

- `pdgo-completion-work`: completion verification and branch handoff
- `pdgo-debug-work`: systematic debugging of a reproducible failure
- `pdgo-dialogue-memory`: conversation memory, checkpoint, retrieval, and handoff
- `pdgo-execute-work`: approved implementation dispatch and continuous stage control
- `pdgo-plan-work`: planning and discovery for a governed multi-stage change
- `pdgo-review-receive`: receiving and deciding an independent review
- `pdgo-review-request`: requesting an independent implementation or code review
- `pdgo-route-work`: startup routing and governed capability selection
- `pdgo-skill-authoring`: authoring and validating a reusable governed Skill
- `pdgo-tdd-work`: test-first implementation of an approved behavior change
