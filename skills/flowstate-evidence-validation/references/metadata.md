# Flowstate Evidence Validation metadata

## Scenario

Check evidence against exact acceptance criteria

## Boundaries

- Do not use outside review, testing, and validation scenarios
- Do not bypass approval, scope, evidence, or safety gates

## Inputs

- classified project context
- plan or task-local artifacts
- current constraints

## Outputs

- evidence decision
- evidence, risks, blockers, and next action

## Prerequisites

- FlowState startup classification
- declared scope
